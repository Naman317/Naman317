### Featured Systems

#### [Virtual-WB](https://github.com/Naman317/Virtual-WB) — Real-Time Collaboration Engine
*High-performance collaborative whiteboard with multiplayer state recovery.*
- Maintained persistent, bi-directional WebSocket connections powered by **Django Channels** for near-zero latency broadcasts.
- Engineered a decentralized peer-to-peer sync architecture for state recovery, eliminating server memory bottlenecks.
- Designed a 60 FPS drawing engine by bypassing standard React state updates during active render loops.
- **Stack:** `React` &bull; `Django Channels` &bull; `WebSockets` &bull; `PostgreSQL` &bull; [Live Demo](https://virtual-wb.vercel.app/)

#### [PeerLink](https://github.com/Naman317/p2p_File-Sharing) — Ephemeral P2P File-Sharing System
*Direct socket streaming application with zero-copy I/O.*
- Built an ephemeral P2P file sharing engine in **Java**, managing dynamic TCP port allocations for direct transfer.
- Eliminated Out-Of-Memory (OOM) risks by building a streaming I/O pipeline using HTTP chunked transfer encoding.
- Implemented multi-threaded daemon with `ExecutorService` and scheduled resource reclamation (TTL cleanup).
- **Stack:** `Java 17` &bull; `TCP Sockets` &bull; `Next.js` &bull; `Docker` &bull; [Live Demo](https://peerlink-share.onrender.com)

#### [TaskMate](https://github.com/Naman317/TaskMate) — SaaS Workspace & Task Management
*Collaborative project management platform with optimistic updates and voice control.*
- Built zero-latency Kanban drag-and-drop powered by optimistic UI updates and Redux Toolkit.

- Implemented 3-tier Role-Based Access Control (RBAC) with cross-origin HttpOnly token transport.
- **Stack:** `React` &bull; `Node.js` &bull; `Express` &bull; `MongoDB` &bull; [Live Demo](https://tasky-one-iota.vercel.app)
